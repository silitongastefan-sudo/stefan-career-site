# Stefan Silitonga — Engineering Portfolio

A responsive, static career portfolio for engineering internship applications. Built with plain HTML, CSS, and JavaScript; no build tools, framework, or paid hosting required.

## Files

- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `resume.docx` — résumé download linked from the hero section

## Included project media

The `assets/` folder contains one robotics prototype photo, five short UAV workshop videos, and generated video poster frames. The videos are embedded with controls and do not autoplay. Keep these files in `assets/` when uploading the site.

The two supplied data-center dashboard screenshots were intentionally not added: they appear to expose internal network/facility details. Only publish sanitized screenshots after removing IP addresses, internal URLs, facility/room labels, and any customer or operational data.

## Project photographs

The selected-project cards now use supplied photographs for the modular cinema drone, tracked rover prototype, and ESP8266 smart-home controller enclosure. A close-up of the drone camera gimbal is also included in the project-media gallery. All images are stored in `assets/`.

Use photos you have permission to publish, and avoid showing confidential data-center information or private facility details.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `resume.docx` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/` after deployment completes.

GitHub Pages hosting is free for public repositories. A custom domain is optional and costs extra. Google Fonts are used for typography; fallback fonts are included.

## Preview locally

Open `index.html` in a browser. Or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.


Additional user-supplied media has been added to `assets/`: robotics and embedded-system prototypes, an ESP8266 local-control interface with its LAN address removed, and sanitized power-monitoring dashboard captures. Review all screenshots and obtain any employer/client permission required before public deployment.
